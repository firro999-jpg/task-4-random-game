# Random Number Guessing Game

This is a simple number guessing game made with HTML, CSS, and JavaScript.

## What I Debugged

While working on this project, I found and fixed different problems in my code.

I learned that uppercase and lowercase letters matter in JavaScript. I also noticed that the order of the code is very important.

Some of my variables and definitions were in the wrong order, which caused logic errors. I reorganized my code and fixed these problems.

I also had a problem with Git because I forgot to add some files before making my commit. I learned that I needed to use:

git add .

Then I made the commit again and pushed my files correctly to GitHub.

## What I Learned

- How to find and fix logic errors
- Uppercase and lowercase letters matter
- How to organize JavaScript code better
- How to use Git commits
- How to add missing files before committing
- How to push my project to GitHub
